# 🌱 Spring Boot & Microservices Mastery – Learning & Projects

This repository contains code, projects, and experiments created while following a comprehensive backend development course covering **Spring Boot**, **Spring Framework Core**, **Microservices**, **Cloud Deployment**, **Databases**, **Messaging Systems**, **Security**, and **DevOps tools**.

The journey starts from **Spring basics** and moves step-by-step through **advanced enterprise-level backend development concepts**.

---

## 📚 Course Roadmap (Topics Covered)

### Core Spring Framework
- Spring IoC Container & Beans
- Dependency Injection
- Auto Configuration
- Spring MVC Concepts
- Spring Bean Data Validation
- Exception Handling in Spring Boot
- Lombok for boilerplate code reduction

### REST API Development
- Building REST APIs with Spring Boot
- Response Object Formatting
- DTO Pattern and Mapping Libraries
- Mini Project: RESTful Web Services

### Data Handling
- SQL & NoSQL Databases
- Spring Data JPA – Basics to Custom Queries
- MySQL & PostgreSQL Integration
- Hibernate ORM + JDBC
- Auditing with Spring Data JPA

### Security & Authentication
- Spring Security 6 with Database authentication
- Registration & Login System
- Google OAuth + JWT Authentication
- Role-based Access Control
- Password Encoding
- Session Management

### Advanced Spring Features
- Spring Profiles (dev/stage/prod)
- Spring Boot Actuator
- Logging & Monitoring
- Aspect-Oriented Programming (AOP)
- Redis Caching & Pub/Sub
- Spring Boot Messaging with Apache Kafka

### Microservices Architecture
- Monolithic vs Microservices
- Service Communication (RestTemplate, WebClient, OpenFeign)
- Service Registry & Discovery (Eureka)
- API Gateway (Spring Cloud Gateway)
- Spring Cloud Bus for Auto-Refresh Config
- JWT in Microservices
- Resilience4J (Circuit Breaker, Retry, RateLimiter)
- Centralized Config Server
- Distributed Tracing (Sleuth & Zipkin)
- Centralized Logging (ELK Stack)

### DevOps & Deployment
- CI/CD with AWS CodePipeline & CodeDeploy
- Dockerizing Spring Boot Applications
- Docker Compose
- Kubernetes (Setup, Orchestration, Dashboard)
- Deploying Microservices to Kubernetes

### Testing
- Unit Testing with JUnit
- Mockito for Mocking
- Integration Tests for Reactive CRUD REST APIs
